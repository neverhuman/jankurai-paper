# Boundaries

This repository is the paper arm of the Jankurai split family: a LaTeX
manuscript plus its data, figures, and build lane. This document is the prose
companion to the machine-readable maps under `agent/`.

## Domain

The product domain of this repo is the **paper** itself. The canonical source is
the TeX under `paper/tex/`, compiled by `latexmk` into `paper/jankurai.pdf`.
There is no Rust crate, web surface, PostgreSQL database, or Python service
committed here, so those stack arms of the family standard are not applicable in
this member.

## What lives where

- `paper/` — manuscript, data, figures, bibliography. Generated TeX tables under
  `paper/tex/generated/` are regenerated from their data sources and must not be
  hand-edited.
- `assets/` — rendered images used by the README and the paper.
- `docs/`, `agent/`, `ops/`, `scripts/`, `tips/` — repo control surface.

## Generated zones

Generated output is never hand-edited. The only generated zone tracked in this
repo is `target/` (jankurai audit output and any routed build artifacts),
declared in [`agent/generated-zones.toml`](../agent/generated-zones.toml). The
compiled `paper/jankurai.pdf` is build output and is regenerated by `just fast`.

## Ownership and proof

- [`agent/owner-map.json`](../agent/owner-map.json) assigns an owner to every
  top-level path that exists in this repo.
- [`agent/test-map.json`](../agent/test-map.json) routes each owned path to a
  deterministic proof command; the paper itself routes to the `latexmk` build.

## Reclassification

If a future change adds a Rust, web, database, or Python surface to this member,
update this document and the `agent/` maps first to declare the new boundary,
then add the matching owner, test, and generated-zone entries before landing the
code.
